《坦克风云 · 经典归来》v0.36.0 — 基地原地科研与持续远征
构建日期：2026-10-05

下载 TankStorm-v0.36.0-portable.zip，完整解压后运行 TankStorm.exe。
Windows x64免安装版，内置Godot与Node运行所需文件；请保留runtime、rules、licenses。
本次公开发布包含此前v0.32—v0.36的本地更新。

主要变化
- 主基地右侧科研中心可原地展开21项科技，滚轮浏览、直接研究、查看剩余时间并金币加速。
  升级、加速、定时刷新与查看详情后返回均保留滚动位置；与建筑清单分别记忆。
  展示完整材料、等级前置、排队状态与不可用原因；仍为1工作位＋3等待位。
- 基地建设清单支持滚轮和原地升级、加速。资源消耗点击即执行，无二次确认。
  取消订单、覆盖或删除预设等仍保留确认，重复请求不会重复扣费。
- 顶栏统一显示资源库存、容量、保护线与产率，移除基地底部重复资源面板。
  功能页可返回原区域和建筑；休整记忆1—720小时输入，直接展示带图标的结算浮窗。
- 普通主线扩至36章576关，核心主线扩至20章320关；沿用既有增长曲线。
  后续守军数量和核心守军科技继续增长；车辆仍七阶，玩家建筑和科研上限仍120。
- 核心重复通关不再产统率书，声望减半；经验及随机双核心保持原规则。
- 世界矿储按地区参考满编运力扩充；75级钛矿示例由1.63M增加至34.71M，采速和守军不变。
- 统率升级提供1/10/100/1000次，成功即停，按实际次数扣费，记录可倒序查询和展开逐次详情。
  统率、声望无玩法等级上限；统率仍不超过声望等级。120级后军衔和0.1%成功率不再变化。
