# 坦克风云原版待验证规则

这些缺口影响历史精度，但不阻止先实现明确标注的原型。公开资料无法恢复所有内部规则；应在找到新的截图、录像、战报或可合法使用的客户端后校准。

## 版本基线

当前用户选择的是“早期基地、造兵、六格编队的经典版”，未指定平台、区服、安装包版本或精确年月。项目暂以 2013 年末至 2014 年阶段的公开资料为经典范围，晚期资料只辅助核对基础结构。不能把每项 2016 年心得都回溯到首发。

研究表述使用“经典玩法复刻”；只有取得可对应到版本号的样本，才使用“某版本精确复现”。

## 纠偏流程

新证据先加入来源目录，再写 observation；与旧材料冲突时保留两个版本和年代。确认后更新规则配置、新 rulesetId、测试样本及相关设计文档。旧存档和战报保持原规则，不能通过覆盖 JSON 默默改变过去的结果。

目前没有要求用户补资料才能继续。只要使用“原型建议”标签，就可以按现有设计开始实现。历史精度与可玩性分别验收，避免一项未确认的老数值阻塞全部建设。
