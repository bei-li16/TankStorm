\section{后续建议，不属于已实现功能}
可逐步拆分原生页面与QA辅助，为RPC建立共享运行时类型检查，按revision缓存读模型，并明确历史和收据的容量策略。收据若裁剪，必须同时定义重试有效期，不能只为减小文件而破坏幂等。

推荐按“类型与数据、领域规则、报价/视图、界面、校验/迁移、手册、测试”检查变更。缺字段必须区分旧版与损坏，不统一补0。

\section{典型需求影响路径}
新增车型须检查车型表、库存键、校验允许值、核心ID、解锁、精灵和声音。新增科技须检查前置、时间系数、默认值、玩家上限、敌军快照与图书馆。修改采集收益须同时核对矿储、运力、刷新、归队仓容及收据。

新增战斗属性先明确其归属：指挥官、单位基础、概率加成或减伤评级，再检查\code{army/simulate/power/attributes}与旧战报。实战公式可以不同于战力估值，但估值不能承诺某个敌人的实际伤害。
