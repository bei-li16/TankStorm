\chapter{持久化、兼容与本机安全}
\section{存档生命周期}
每档具有ID、主JSON和\code{.backup}；\code{active.json}保存当前选择。新建先写两份再激活，失败仅清理由本次安装创建的文件。读取主档失败尝试备份并提示；两份都坏时保留文件供诊断。

命令立即提交，背景tick先标记脏，每10秒左右刷新主档，切换与退出也刷新。最近几秒纯时间增长可能未落盘，重启后重新推进。备份主要对应上次操作，而非每次tick快照。

\section{导入与迁移}
封装含\code{format/schema/ruleset/state/checksum}。checksum为规范化JSON的SHA-256，规范化排序对象键并保留数组序。它检测损坏，不是数字签名或防作弊。

导入核对封装和校验和，执行结构/语义校验，启用兼容扩展，再复验。结构检查类型、整数、规模和危险键，语义检查订单、库存和内容关联。扩展函数仅补合法旧缺项，不应静默重置现代损坏字段。

世界按\code{worldRules/economyVersion/protectionVersion/reserveVersion}迁移；旧矿保留剩余比例；在途目标延期迁移。防御快照用字段存在性区分旧评级与新基础值，历史事件不重算。

当前总规则为\code{classic-prototype-v0.1}，战斗规则为\code{classic-combat-v0.39}，应用为0.40.0，分别承担不同兼容职责。

\section{回环服务和管理入口}
服务只监听回环，要求POST、精确路径、Bearer令牌并拒绝Origin头；请求体超过280000000字节销毁连接。父进程探测避免服务长期遗留。

root管理使用scrypt和随机盐保存口令摘要，解锁20分钟，连续5次失败冷却1分钟，限制原生模拟充值入口。这是本机误用与浏览器跨源防护，不阻止拥有进程和文件读写权限的本机用户修改游戏。

IndexedDB数据库\code{tankstorm-classic-v1}具有\code{saves/backups}。同一readwrite事务中读取、计算、校验、写备份与主值，失败整体回滚；跨标签串行由IndexedDB承担。原生多文件替换没有同样的数据库事务语义。
