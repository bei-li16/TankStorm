# 原版视角战场改版 · v0.5.0

2026-10-02。Windows 原生离线版。本次替换 v0.4 的左右平铺战场，依据用户提供的原版截图重新设计。

## 参考与边界

- 用户截图：我军位于左下，敌军位于右上；六格阵位投影成斜向三列、两层纵深；中央细窄的斜向景物折叠；小型兵力旗标；多目标同时爆炸和跳出伤害数字；顶部 VS、底部跳过。
- [官网《坦克风云》排兵布阵，2016-09-05](https://tk.rayjoy.com/wap.php?action=article&id=62)：四兵种、前后排、轮次、火箭覆盖前后排及阵位策略。本文仅依据其描述确定表现逻辑，不采用攻略作者的平衡判断作为本游戏数值。
- 宽屏位置、动画时长、折叠投影函数、美术和界面均为本项目重新设计。没有原版源代码，不将推断的相机机制称为官方实现。

## 实现

1600×900 逻辑画布保留宽屏比例。场景采用固定高位等距视角：我军左下朝东北，敌军右上朝西南。前排仍为 1/2/3，后排为 4/5/6，战斗规则中的同列关系不变。根据投影后的地面深度排列绘制顺序。

斜向折叠线由 `y=184+x×115/305` 定位，沿线三个不规则明暗折面压缩地面纹理。两侧地面向各自车辆行进方向的反方向滚动，车辆轻微颠簸、炮口后坐、履带后方扬尘。植被和石块主要在外缘，保持阵位清晰。

车辆使用新增的四张战斗图集，28 辆车各有东北、西南两个视图，共 56 个战斗贴图。车身始终保持直立的等距视角。每张图记录实际炮口、炮轴原点和透明轮廓；轮廓多边形避免临近图格的炮管混入。军械库和其他界面保留原有大幅模型。

直射炮弹从炮口沿物理炮轴出发。跨过中央折叠时隐藏被压缩的距离，并在目标一侧重新出现；火箭和火炮的曲线起始切线沿炮轴，随后进入折叠带。不能把两个不同相机区域的屏幕坐标直接连线，否则跨列射击会让整辆车的贴图旋转倾斜。该处理属于本项目的视觉近似，并非三维炮塔模型。

## 回放与 UI

- 连续的相同 `round / side / from` 命中事件合并成一次开火动作。火箭一次齐射可以同时命中六个目标；火炮一次行动命中同列目标。保留原始事件顺序与数值。
- 初始接敌和相邻开火间隔 1.05 秒；炮弹在开火后 0.32 秒到达，届时更新兵力并显示爆炸和伤害。最终爆炸消退后显示结果。
- 暂停冻结地面、车辆、炮弹、爆炸和数字；1/2/4 倍速使用同一时钟。大步长逐段推进，不丢失已经开始的攻击。
- 跳过直接显示结算快照，并用剩余生命重新计算存活数量；修复旧版跳过后数量可能仍显示开战数量的问题。重播从初始快照重置，不再发放奖励。
- 顶部紧凑的金属色 VS 面板，底部控制条；绿色跳过按钮、小兵力旗标、细生命条。鼠标悬停车辆查看名称、阵位和生命。
- 结算提供详细战报、重播和返回，核心奖励在详细战报中列出。

## 素材与源码

内置 image_gen 生成原创素材。完整提示词、源文件路径和火箭图集修订记录见 `native/assets/manifest.json`、`artifacts/asset-generation-v05.json`、`artifacts/asset-generation-v05-rocket-fix.json`。

- `native/assets/battle_tank.png`、`battle_tank_destroyer.png`、`battle_spg.png`、`battle_rocket.png`：透明战斗图集。
- `native/assets/battle_terrain.png`：草土地面；`battle_edges.png`：透明外缘植被岩石。
- `native/assets/battle-sprites.json`：56 个视图的图集区域、轮廓和炮口坐标。
- `native/scripts/game.gd`：场景绘制、回放分组、折叠弹道和原生窗口验证。
- `native/tests/aim.gd`：28 车型 × 双方 × 六个来源阵位 × 六个目标，共 2,016 组弹道起点、终点和炮口切线检查。

## 验收与交付

回归规则、生产、核心、改装和存档测试沿用原有测试套件。专用视觉战报通过实际规则引擎 `simulate` 生成，明确标为演习；自动验证使用隔离存档，避免修改玩家档案。

实机记录位于 `artifacts/native-v05/`：完整流程 `smoke.json`；六目标齐射、命中时机、暂停像素冻结、三档倍速结算一致、跳过人数、1120×630 最小窗口和满编帧率记录 `battle-scene.json`；另附场景、弹道、齐射、结果和窗口缩放截图。便携包完整性记录 `package-manifest.json`。

发布目录 `release/TankStorm-v0.5.0/`。保持原来的离线 Windows EXE 和多存档功能，存档格式、资源与兵种平衡无变更。旧版本目录保留；根目录启动脚本指向新版。

最终验收：129 项规则测试全部通过，TypeScript 与格式检查通过；2,016 组弹道检查通过；导出 EXE 的原生全流程与六目标齐射验证通过。GTX 1060 满编场景实测约 58 FPS（包含窗口恢复时的开销），P95 帧时 16.67 ms；一般场景约 60 FPS。ZIP 已验证 CRC 与全部 6 个文件的 SHA-256，文件大小 119,101,539 字节，哈希详见发布清单。
