TankStorm v0.30.0 — 独立车间、生产报价与战斗反馈
日期：2026-10-04

本轮对应最新反馈的八项改动

1. 新制造、改装单笔上限由100增至500；快捷数量为50 / 100 / 500 / MAX。
   MAX依然受材料、核心、原型车限制。501辆请求会整笔拒绝，不扣材料。
   维修保留独立数量规则。旧存档已付费大订单按原数量、费用、工期继续交付。
   本次不改变单辆生产曲线：500辆的原始工时是100辆的5倍，整单仅减一次VIP免费时长。

2. 普通命中用26号浅色数字；暴击用32号橙红数字和“暴击”文字；闪避为独立浅青提示。
   取消重复的第二行暴击文字，击毁与克制反馈继续保留。

3. 顶部、基地和资源区库存条采用相同语义：白色标尺为仓储保护线，绿色为受保护部分，橙色为超过保护额度部分。
   保护比例直接读取既有仓库规则（20%—40%），没有再引入另一套比例。
   悬停显示保护额度、实际受保护库存和可掠夺数量；超仓仍保留文字说明。

4. 底部移除工厂、科研，保留基地、编队、战役、世界、指挥官、战报。数字快捷键改为1—6，帮助与图书馆同步。
   工厂和科研通过基地建筑进入，保留调度中心的直接操作和导航功能。

5. 第一工厂、第二工厂、改装厂各进入对应独立车间，标题明确厂名和等级。
   移除跨厂分页和制造/改装混合切换；当前车间只展示本厂工作与三条等待订单。
   返回工业区继续选中本厂，即使从调度快捷入口进入也保持对应关系。

6. 左侧增加单位制造与单位改装材料、核心、原型车数量和工时；改装页面保留原车→目标比较。
   订单区分开显示整批工时、等待时间、VIP减免后工时和预计全部交付时间。
   两座制造厂一直使用各自等级计算速度，本轮让此差异明确可见；不重复修改速度规则。
   改装页的制造参考价采用两座制造厂中等级较高的一座，并注明厂号、等级。
   维修与调度报价补充单辆和整批工时。既有订单使用原快照，新报价只应用于新订单。

7. 一方最后一次命中结束至另一方开火的间隔增加50%，不改变伤害规则、连发间隔或火箭六发偏移。
   1倍速：普通换手命中后空档0.73秒→1.095秒；火箭六发最后命中后0.31秒→0.465秒。
   坦克/火炮同次行动的0.52秒独立射击和火箭快速齐射仍保留。
   同侧追加行动不额外增加换手等待。回放依照原事件，动画速度不重新结算。

8. 经典战役首通：1技能点、1统率书、原有声望、金币、资源和经验。
   重复胜利：原有重复资源、首通声望的一半（向下取整）、正常经验；无金币/书/技能点。
   详情页显示首通/重打对应内容。VIP经验规则不变，页面经验明确标为基础经验。
   核心行动保持自己的独立掉落规则。旧报告、历史奖励不追扣、不改写。

关键改动文件
native/scripts/game.gd：导航、车间报价、保护条、伤害数字、换手动画、维修与调度时间说明、原生界面验收。
src/core/growth.ts、src/core/engine.ts：500辆限制与原子校验。
src/core/content.ts：经典战役首通和重复奖励。
native/rules/bridge.ts：向原生UI传递统一的批量上限。
src/core/library.ts、README.md、native/PLAYER_GUIDE.txt：现行规则和入口说明。
tests/workshops-v30.test.ts、既有上限/奖励断言、native/tests/workshops30.mjs：规则和独立UI验收。
package.json / package-lock.json / native/project.godot / native/export_presets.cfg：0.30.0版本信息。

验证结果
1. npm test -- --maxWorkers=2：34个文件、581项全部通过。
   包括多队列和大跨度结算、库存守恒、旧订单快照、MAX材料与核心约束、500/501边界、扣费幂等、首通/重复奖励、历史战报存取。
2. npm run check：TypeScript与Prettier通过；Godot --check-only及正式Windows导出通过。
3. 原生验收 V30_WORKSHOPS_QA=true：从工业区依次进入两座制造厂与改装厂，每厂提交500辆并验证独立队列、费用和工期快照。
   验收样例：VII阶坦克，第一厂60级单辆1794255毫秒，第二厂90级1766328毫秒；70级改装厂975306毫秒。
4. 1180×680、1280×720、1920×1080、2560×1440，各100%及120%字号：基地、制造、改装、战役截图检查；另检查全屏。
   修正小窗口放大字号时的等待列表行距。
5. 原生坦克/火箭回放分别在1/2/4倍速核对换手间隔和最终生命/数量；空地弹坑保留。普通命中与暴击分别截图。
6. 使用Windows computer-use实际点击返回工业区、选择第一工厂、进入车间及50辆快捷数量，观察整批工时联动。
   验收采用独立smoke存档，不导入、不编辑玩家主存档，原v0.28游戏窗口保持打开。
