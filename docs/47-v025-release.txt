《坦克风云 · 经典归来》v0.25.0 — 维修、结算与侦察体验

Windows x64 原生单机免安装版。
下载 TankStorm-v0.25.0-portable.zip，完整解压后运行 TankStorm.exe。
无需安装 Godot 或 Node.js，请保留 runtime、rules、licenses 文件夹。
GitHub 自动生成的 Source code 是源码包，不是游戏程序。

本次更新

- 维修列表默认只列当前待修、维修中的车型；支持切换历史损失。
  材料不足显示缺额，暂无待修时不再展示无意义的材料报价。
- 结算页每页十项奖励，经验、声望、统率书、技能点使用独立标识。
  点击奖励可看精确数量；详细战报同时列出普通资源、核心和成长奖励。
- 无损胜利不再提示维修；演习明确实际未扣兵。
  新增“下一关·备战”，取消不会出战；“再次挑战”保留直接重打。
- 守军详情改为六阵位侦察卡，兵种、数量、攻击、生命、先手与二次开火对应展示。
  保留未知、过期、侦察时空阵位的区别，不读取未侦察守军信息。
- 地图保留已选目标，并提示它位于筛选条件之外；可一键显示全部。
  没有可出征部队时显示调整编队提示，远征条目显示目标名称和坐标。
- 休整归队摘要关联对应远征的历史战报，即使战斗发生在休整之前。
  缺少旧战报时不把未知战损当作零；不修改原始战报或归队凭据。
- 确认弹窗按内容重新调整尺寸，增加背景遮罩，隐藏下层数量输入框。
  通知移至上方，减少与禁用原因提示重叠。
- 编队大额生命/战力使用简写，选中阵位展示当前配置，候选车展示替换对比。
  坦克说明统一为逐列前排优先、1—3发；保留原射击规则。
- 结算背景沿用对应战场主题，伤害数字缩小并简写，去除重复击毁文字。

兼容与分发

- 本版没有更改战斗伤害、经济曲线、队列时长或存档格式。
- 保留 v0.24.3 的50大回合规则；旧40回合战报仍按原快照回放。
- 测试使用独立 smoke 存档，未向玩家主存档写入评测数据。
- 版本号统一为0.25.0，Windows文件/产品版本为0.25.0.0。
- Git仅提交源码、文档及测试；EXE、内置运行时和ZIP仅作为Release附件。
- 提供便携包SHA-256校验文件。

本轮边界

本次发布整合当前工作区的体验改动，没有新增章节或重新平衡经济。
自动化原生验收与截图检查不能替代多日完整成长实玩；后续继续根据反馈迭代。
本地完整验收输出保留在忽略目录 artifacts/native-v25/ 和 artifacts/native-v243/。
