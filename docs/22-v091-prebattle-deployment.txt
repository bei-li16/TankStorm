TankStorm v0.9.1 — 战前编队确认

操作流程
战役“发起进攻” → 战前编队 → “确认出战” → 战斗回放与结算。
核心副本和战术演习使用同一流程；演习按钮标为“确认演习”，仍不消耗部队、不发奖励。

战前编队
沿用六格阵位、前后排与待命装甲列表。点击阵位后换车，拖动阵位交换位置。
支持数量增减、直接输入、MAX、清空阵位、自动满编和载入已有预设。
“查看敌军部署”在右侧切换敌军六格预览，再点“返回待命部队”继续调整。
单格统率与同车型合计库存共同限制出战数量；空编队和不足库存禁止确认。

保存与取消
调整只保存在本次战前草稿，查看敌军、自动满编、载入预设都不会提交战斗或保存阵型。
确认出战才把阵型与战斗作为一个操作提交，保存新阵型并结算。
返回、Esc 或切换到其他页面会取消本次战前调整；进入前的编队草稿保留。
战前按 F5 提示“确认出战时保存”，不提前覆盖当前存档编队。
等待确认期间正常资源生产、队列和已出征部队继续推进。
确认时再次检查库存，失败保留战前界面与草稿，不静默减少出战数量。

实现与兼容
Windows 原生 Godot 界面增加 deployment 状态，不引入网页页面。
原有 battle / dungeon 命令新增可选 formation 字段；旧客户端调用与旧存档仍兼容。
显式阵型在 execute 的克隆事务内检查、写入、模拟、结算；失败不覆盖存档或部分扣兵。
客户端提交时锁定操作；相同请求编号重试返回原战报，不再次发奖或结算。
战前目标在打开界面时固定；调整过程不会受后续列表选中项影响。
世界采矿/突袭的行军入口保持原流程，本更新覆盖即时战役、副本和演习。

验证
规则测试覆盖：指定六格/数量、空阵/超统率/重复车型超库存/无效车型、过期库存、
锁关与锁副本、演习无战损、核心奖励、存档往返、旧命令兼容及重复请求原战报。
Windows UI 验证覆盖：点击进攻只打开部署、敌军预览、输入数量、拖动阵位、
取消恢复既有草稿、空阵禁用、自动满编只改草稿、确认只开战一次、核心预览与 Esc 返回。

发布
