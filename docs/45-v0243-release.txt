《坦克风云 · 经典归来》v0.24.3 — 五章核心战线与战斗体验更新

Windows x64 原生单机版。下载附件 TankStorm-v0.24.3-portable.zip，完整解压后运行 TankStorm.exe。
无需安装 Godot 或 Node.js。请保留 runtime、rules、licenses 文件夹；GitHub 的 Source code 下载项是源码，不是游戏程序。

本次更新（相对 v0.23.0）

- 核心行动扩展为 5 章 ×16 关，共80关。难度、工厂门槛和核心产出逐步提升，每关产同一车系的两种核心，首通固定、重复随机，并展示具体掉落区间。
- 火箭车每轮六发只播放一次原发射音和一次连环命中音，首末着弹间隔约0.42秒。空位着弹保留随背景后移的弹坑。
- 自行火炮、火箭车从炮口方向直线射出，分别以约60°、45°斜向下落弹，消除折叠视野处的突兀变向。坦克、歼击车保持原平射。
- 战场左上仅显示当前攻击方与兵种；VS下方仅显示当前大回合/上限，如12 / 50。
- 新战斗最多50个大回合。第50回合全部行动和连击完成后仍未分胜负，先手方负；回合内歼灭敌军仍正常获胜。结算注明超时原因。

存档兼容

- 保留原核心主线通关资格、已领取的首胜、核心库存及已付费订单，原16关映射到新章节。
- 旧战报保留原快照、40回合上限和原胜负；回放不重复结算奖励。
- 新战报记录独立回合上限与结束原因，含新战报的存档请使用 v0.24.3 或更新版本。
- 程序更新使用原用户目录存档；所有发布验收使用隔离测试存档。
